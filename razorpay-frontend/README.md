# 🛍️ Razorpay Storefront Agent - Frontend

Conversational AI Shopping interface built with **React 18**, **Vite**, and **Tailwind CSS**.

## ✨ Highlights
- **Live Inventory Sidebar**: Displays live store products and prices with interactive hover states.
- **Conversational Sales Rep**: Powered by Groq LLM with function calling to query catalog and generate instant Razorpay payment links.
- **Glassmorphic Theme**: Clean, responsive, and modern fin-tech UI.

## 🏃 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

App runs at `http://localhost:5173`. Make sure the backend (`http://localhost:8000`) is running.
